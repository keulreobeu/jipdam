## 추가 문서와 정형 데이터의 우선순위

**첫 RAG 실험에 필요한 문서:** 임대차 관련 법령·시행령·공식 계약 확인 안내, HUG/HF/SGI 기관별 보증 안내·FAQ를 작은 검수 집합으로 만든다. 발행기관·URL·문서/상품 종류·관할·주택유형·발행일·효력기간·개정 관계·라이선스·원본 해시·조문/페이지/표 위치·파싱 상태를 보존한다. 법률 요건의 현재 내용이나 특정 기관의 수집 API 사용 가능 여부는 이번 분석에서 확정하지 않았다.

2026-10-21 이후 보완 수집 및 검수 기록은 위 2026-10-22 현황과 [TASK-LEGAL-RAG-CORPUS-001](tasks/legal-rag-source-snapshot-20261021.md)을 따른다. 당시 작성한 문장 중 약관 원문 미수집·SGI 원문 미확보 등은 후속 확보 전의 과거 상태이며 현재 상태로 해석하지 않는다. 법령 묶음은 [법령 패키지 v2](../data/raw/legal_rag/legal_rag_law_current_20261021_v2.zip), 기관 묶음은 [최신 기관 패키지 v34](../data/raw/legal_rag/legal_rag_institutional_20261021_v34.zip)에 있다. 출처별 수집 기록은 GitHub [#24](https://github.com/keulreobeu/jipdam/issues/24)~[#28](https://github.com/keulreobeu/jipdam/issues/28)에 기록했다. HUG의 2017/2020/2024 판본과 HF·SGI 약관은 보존 원문 및 제한된 추출/페이지 확인까지이며 전체 법률 검수는 미완료다. 법제처 인증 API를 사용하지 않았고, 사용자 보류 요청은 유지한다. 별도 프로젝트에 원문 후보 4건을 분리한 로컬 retrieval 미리보기를 만들었다. 원문 상태는 미검수로 표시하고 기본 KnowledgeScope 차단을 유지하며, 의미 검색·생성 평가는 남아 있다.

**실추천에 필요한 데이터:** 취소·정정 상태의 공식 근거가 최우선이다. 단지 관계 승인만으로 거래를 유효하다고 만들지 않는다. 검수 단지 좌표·역/마트/공원/병원 자료와 커버리지는 위치·시설 조건에 필요하다. 제공 원본이 있으면 먼저 재사용 가능성을 확인하고, 추가 수집과 서비스 연결을 분리한다.

**확장 요구가 정해졌을 때 필요한 자료:** 학교 배정은 통학구역/고시, 도보시간은 단지/역/시설 입구와 검수 보행 네트워크, 반려동물 허용은 관리규약/계약 근거가 필요하다. 어린이집 차량 운영과 실제 단지 픽업 가능 여부도 다른 필드다. 청약·지원정책·지역계획·재난 해설은 첫 RAG 실험에 필수인 것으로 묶지 않는다.

## 별도 프로젝트 실험의 인수 기준

| 항목 | 받아야 할 산출물 |
| --- | --- |
| 재현성 | 실험 저장소/commit, 재현 명령, 모델·파서·청킹·인덱스 버전, 코퍼스 manifest/hash·이용조건 |

제공 설계서의 Recall@10 ≥0.90, 주요 주장 근거 일치율 ≥0.98, 고위험 위반 0건은 **초기 목표 제안**이며 달성값이 아니다. 평가 표본·분모·검수자·측정법·실패 사례와 함께 채택 여부를 판단한다. 전체 240문항 제안은 정형/GIS/혼합까지 포함하므로 문서 RAG 단독 실험 완료 조건으로 자동 전용하지 않는다. 다른 도메인에서 엔진 동작을 시험했어도 집담의 한국어 임대차 원문에 대한 도메인 검증은 추가로 필요하다.

실험용 프로젝트 위치와 담당자는 지정되지 않았다. 이번 작업에서 별도 프로젝트/채팅을 만들거나 실험을 실행하지 않았다.

## 이번 작업 검증과 한계

- 제공 설계서, 현재 계약·관련 ADR·코드·수입/검수 증거를 대조했다.
- 검수 serving을 읽기 전용으로 열어 위 행 수·연결·상태·좌표·시설·coverage 집계를 확인했다.
- 같은 DB에서 보증금 상한 500,000,000원의 전세 요청을 실제 추천 함수에 전달한 결과 `status=data_not_ready`, `count=0`, 사유는 `취소·정정 상태의 추가 검수가 필요합니다.`였다.
- 기존 KAN-8~10은 원래 설명·상태·배정자를 바꾸지 않고 보완 코멘트를 추가했다. KAN-13~16은 후속 작업으로 열어 두며, 이번 추가 원문은 KAN-13과 GitHub 수집 Issues #24~#28에 추적한다.
- Jira 선후행 연결은 KAN-13 → KAN-14 → KAN-16에 `Blocks`로 등록했다. KAN-15와 KAN-16은 관련 작업으로 연결했다. KAN-15는 실제 후보를 결합할 때 필요한 조건이며 순수 지식 응답의 전역 차단 조건은 아니다.
- 설명 문서의 로컬 상대 링크, 필수 이슈 참조, 줄 끝 공백/최종 개행 검사를 통과했다. Jira에서 KAN-13은 `진행 중`, KAN-14~16은 `해야 할 일`로 확인했다. 제품 코드·canonical/serving 계약·설정은 변경하지 않았으며 전체 제품 회귀·실모델 평가·RAG 성능 시험은 이번에 실행하지 않았다.
- 이 문서는 분석 설명이며 Spec/ADR/Task의 대체 승인이 아니다. 원문은 별도 RAG raw 폴더에 수집했지만 법제처 API/OC 호출·색인·제품 적용·지오코딩·매칭 확정·DB 수정·Drive 업로드·Git push/배포는 실행하지 않았다.
