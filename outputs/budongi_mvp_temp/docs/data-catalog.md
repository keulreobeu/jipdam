## 활용 경로

1. **분석·시장 맥락:** MOLIT 관측으로 계약 분포를, KB 통계로 주간·월간 시장 흐름을 따로 계산한다. 비교할 때 기준 기간, 단위, source_view, 원본 업데이트 메모를 표시한다.
2. **데이터 품질·재현:** canonical 계보, staging 사유, 원본 hash, batch/version 이력을 이용해 누락·중복·정규화 오류를 조사한다. 거래 관측의 재실행 결과는 원본 행과 조인해 대사한다.
3. **사용자 설명·검색 준비:** 법령·계약서·보증기관 자료는 인용 위치와 원문 버전을 확인하는 사람 검토 자료로 우선 사용한다. 문서별 이용조건과 검색 평가가 확인된 자료만 별도 RAG 실험에 넣는다.
4. **실제 추천:** 확정 관계, 거래 상태, 허용된 좌표·시설 데이터가 준비되고 관련 검수가 완료된 serving 데이터만 입력으로 사용한다. 현재 실제 추천은 데이터 준비 게이트에 걸려 있다.

## 별도 취급 또는 사용 제외

- 합성 rental demo는 테스트·시연 자료이며 수집 실적이나 실제 시장 근거로 계산하지 않는다.
- 법제처·법무부·HUG 후보 원문 묶음은 별도 검색 실험 산출물이며 집담 추천용 거래 데이터가 아니다.
- 좌표·시설 출처는 이 데이터 인벤토리의 수집 완료 항목으로 간주하지 않는다. 새 수집·지오코딩은 별도 승인이 필요하다.
- 2023 역사 snapshot, 2024년 이후 최신 관측, 사용자 제공 통계는 저장·평가 경계를 유지하고 하나의 기간 시계열로 무표시 결합하지 않는다.
