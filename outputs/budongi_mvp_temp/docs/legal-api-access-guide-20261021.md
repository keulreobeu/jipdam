# 법률 RAG 원문 API 신청·인증값 준비 안내

기본 작성일: 2026-10-21; 최신 상태 확인: 2026-10-22. 연결 작업: [KAN-13](https://kwulreobeu.atlassian.net/browse/KAN-13). [RAG 적용 분석](rag-readiness-assessment-20261021.md)의 공식 문서 준비를 위한 안내와 사전 수집 기록이다. Law.go 인증 API는 호출하지 않았다.

## 2026-10-22 현재 수집 상태

- 법제처의 공개 현행 법령 2건은 [패키지 v2](../data/raw/legal_rag/legal_rag_law_current_20261021_v2.zip)에 보관한다. 공식 이용안내는 영리 목적을 포함한 자유 활용과 출처 표시를 허용·요구한다. API 신청/승인 상태는 확인하지 않았으며, 사용자 지시에 따라 인증값 확인·OC/API 호출·과거 시행본 본문 수집은 보류한다.
- 기관 원문은 [패키지 v34](../data/raw/legal_rag/legal_rag_institutional_20261021_v34.zip)에 보관한다. HUG 약관 PDF/HWP/HWPX와 2017 user-provided historical PDF, HF 일반전세지킴보증 PDF, SGI 개인임차인용 2025-04-01 공식 PDF가 확보되어 있다. HUG 2017 PDF의 정확한 공식 게시경로는 찾지 못했다. 세 보증기관 약관의 문서별 재사용 권리와 본문/법률 검수는 미완료다.
- SGI 공식 PDF는 native text layer를 직접 읽고 약관 목차-본문 페이지 위치를 확인했으며, HF PDF의 수기 위치표도 별도 포함한다. 기존 SGI 화면 렌더링 캡처는 원본 HTML이 아닌 파생자료다. 색인·canonical/serving 반영·Drive 업로드는 하지 않았다.

자료별 상세 provenance와 미완료 조건은 [TASK-LEGAL-RAG-CORPUS-001](tasks/legal-rag-source-snapshot-20261021.md) 및 각 패키지 manifest/validation이 기준이다. 아래 API 절차와 첫 수집 기록은 준비 참고용이며, 현재 실제 신청/승인/발급 상태로 해석하지 않는다.

## 먼저 준비할 것

**법령 원문의 우선 경로는 법제처 국가법령정보 공동활용 Open API다.** 발급/신청 사이트는 [국가법령정보 공동활용](https://open.law.go.kr/LSO/main.do)이며, API 인증 파라미터 이름은 `OC`다. [공식 API 가이드](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdListGuide)는 신청한 API 인증값을 필수로 요구한다.

RAG에 필수인 것은 검수한 원문이다. API는 법령을 반복 확보·갱신하는 경로로 적합하고, 별도 프로젝트의 작은 실험은 이용조건을 확인한 제공 원문 파일로도 시작할 수 있다. 매 질문마다 법령 전체를 실시간 조회하기보다, 원본과 문서 버전을 보존하고 검수·색인한 집합을 검색하는 방향을 권한다. 이는 집담 적용을 위한 제안이며 현재 구현은 아니다.

## 어디서 신청하고 확인하나

1. [공식 회원가입 화면](https://open.law.go.kr/LSO/usrJoin.do)에서 본인 인증·가입을 진행한다. 기존 회원은 로그인 후 `OPEN API → OPEN API 신청`으로 이동한다.
2. API 신청정보의 **API인증키(OC)**를 설정한다. 현재 화면은 사용자가 직접 지정하는 방식이며, 이메일 앞부분을 자동 인증값으로 가정하지 않는다.
3. 시스템명·기능 설명·활용목적과 도메인/서버 IP 관련 항목을 실제 실험 환경에 맞게 작성한다. 로컬 실험의 등록 방식이 불명확하면 운영기관에 확인하며 가짜 주소/IP를 넣지 않는다.
4. 신청할 자료 종류와 출력 형식을 선택한다. 아래 최소 신청 범위를 참고한다.
5. 신청 후 **마이페이지 → API인증키관리**와 신청 상태를 확인한다. 인증값 원문은 Jira나 공유 문서에 기록하지 않는다.

위 경로·직접 지정 방식·입력 항목은 [현재 공식 신청 화면](https://open.law.go.kr/LSO/usrJoin.do)에서 확인했다. 현재 화면은 자동승인을 안내하지만, [일반 이용안내](https://open.law.go.kr/LSO/information/guide.do)는 심의와 1~2일 처리를 안내한다. 안내가 다르므로 즉시 사용 가능/고정 대기일을 보장하지 않고 실제 신청 결과를 기준으로 한다.

신청 설명에 담을 내용의 예: 한국어 주택임대차 관련 법령 원문을 별도 연구 프로젝트에서 검색·인용 평가하고, 검증 후 집담의 공식 근거 설명 기능에 활용한다. 법령명·조문·시행일·원문 출처를 보존하며 법적 판단이나 보증 가입 확정을 자동 제공하지 않는다. 실제 시스템명·목적·공개 범위는 신청자가 사실에 맞게 작성한다.

## 최소 신청 범위와 후순위

| 우선순위 | 신청/활용 대상 | 쓰임과 주의 |
| --- | --- | --- |
| 먼저 | 대한민국 현행법령 목록·본문, XML 또는 JSON | 주택임대차 관련 법률·시행령의 원문과 메타데이터 확보. 법령마다 별도 키를 받는 방식으로 계획하지 않음 |
| 먼저 | 법령 연혁(+현행) 목록·본문, 제공되는 XML | 과거 계약 시점·개정 전후 비교. 현행 원문만으로 과거 답변을 만들지 않음 |
| 같은 법령 서비스에서 확인 | 시행일 기준 목록·본문, 조항호목, 변경 이력 | 공포일과 시행일 구분, 조/항/호 인용·개정 영향 확인. 신청 항목별 실제 이용 범위는 승인 결과로 확인 |
| 필요한 경우 추가 | 행정규칙·자치법규 | 공식 지침·서울/자치구 규정 등 실제 질문 범위가 정해졌을 때 |
| 후순위 | 판례·법령해석·생활법령·지능형 검색 | 첫 문서 검색 실험과 분리. 별도 제공 범위/서비스를 확인한 뒤 추가 |

서비스 목록은 [공식 활용가이드 목록](https://open.law.go.kr/LSO/openApi/guideList.do)에서 확인했다. 시행일 기준 API는 [목록](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdListGuide)과 [본문](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsEfYdInfoGuide)을 함께 확인한다. 본문은 법령 ID 또는 버전 식별자 MST를 사용하고, MST 방식에서는 시행일 인자도 필요하다. 법령 연혁은 [연혁 목록](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsHstListGuide)(`target=lsHistory`)과 [연혁 본문](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=lsHstInfoGuide)을 별도 사용한다. 현행 ID 조회와 특정 시행 버전 조회를 구분한다.

## OC와 요청 URL은 별개

OC는 신청·관리 화면에서 사용자가 설정하는 인증값 하나다. 호출 프로그램은 이 값을 안전한 보관함에서 읽어 각 요청의 `OC` 파라미터에 전달한다. 완성된 호출 URL이나 법령 데이터를 OC 대신 저장하는 방식이 아니다. 이 문서·Jira·소스 관리에는 실제 OC를 적지 않는다.

공식 가이드의 기본 경로와 필수 파라미터는 다음과 같다. 값은 예시 자리표시자이며 실제 인증값을 포함하지 않는다.

| 용도 | 공식 경로 | 필수·주요 입력 |
| --- | --- | --- |
| 현행법령(시행일 기준) 목록 | `lawSearch.do` | `OC`, `target=eflaw`, `type=JSON` 또는 `XML`; 법령명은 `query`, 연혁/예정/현행 구분은 `nw`, 결과는 `display`·`page` |
| 현행법령(시행일 기준) 본문 | `lawService.do` | `OC`, `target=eflaw`, `ID` 또는 `MST`, `type`; `MST`를 쓰면 `efYd` 시행일도 전달 |

공식 가이드 문서의 요청 URL 표기는 HTTP다. 연동 전 HTTPS 지원·리다이렉트·호출 로그에서 `OC` 마스킹 여부를 확인하고, 인증값이 URL에 포함된다는 점을 전제로 서버 로그·오류 메시지·프록시 기록에 노출되지 않도록 해야 한다. OC를 포함한 호출 URL을 Jira·문서·터미널 출력·브라우저 저장소에 복사하지 않는다. 현재 집담에는 이 API용 호출 어댑터가 없으므로, 키를 발급/저장한 사실만으로 실제 호출이 준비된 것은 아니다.

문서 실험의 첫 후보는 `주택임대차보호법` 및 시행령이다. 목록 응답에서 법령ID·법령일련번호·현행연혁코드·공포일·시행일을 확인한 뒤, 현행 버전과 필요한 과거 시행 버전을 각각 조회한다. API 인증 성공, 요청 프로토콜, 이용조건, 반환 건수와 실제 원문 수집은 아직 검증하지 않았다.

첫 대상 법령 후보는 `주택임대차보호법`과 관련 시행령이다. 계약 일반 설명에 필요한 민법 등의 추가 범위는 평가 질문을 기준으로 정한다. 이름 검색 결과를 전부 수집하거나 서로 다른 개정 버전을 현행으로 합치지 않는다.

## 보증기관 안내까지 같은 키로 해결되지는 않는다

| 자료 | 확보 경로 | API 키 준비 판단 |
| --- | --- | --- |
| 법률·시행령·지원되는 법령정보 | 국가법령정보 공동활용 API | 우선 `OC` 신청 |
| HUG 보증 안내·FAQ | [공식 상품 안내](https://m.khug.or.kr/hug/web/ig/dr/igdr000001.jsp?tabMenu=Y), [공식 FAQ](https://onestop.khug.or.kr/webView/webBiz/common/faqList)의 원문/첨부자료 | 해당 설명문 전체를 제공하는 공개 API는 이번 조사에서 확인하지 못함. 이용조건을 확인한 문서 확보 계획을 별도로 수립 |
| HF 보증 안내·업무지침 | [HF 공식 사이트](https://www.hf.go.kr/ko/index.do?hl=ko-KR)의 주택보증·전세보증금반환보증·제도 안내 | 법제처 OC로 기관 상품 안내까지 제공된다고 가정하지 않음. 공개 안내/문서 경로부터 확인 |
| SGI 상품 안내·약관 | 개인임차인용 공식 상품 안내와 2025-04-01 약관 PDF 확보 | 임대인용/법인임차인용 상품을 섞지 않는다. 약관 본문 전체 법률검수·문서별 이용조건은 미완료; 약관 원문 API는 확인되지 않음 |

기관 안내가 공개되어 있다는 사실은 자동 수집·재배포 허용이나 API 제공의 증거가 아니다. 기관 문서의 이용조건·갱신·적용 상품을 확인한다. 기존 HUG 사고 통계용 데이터/API와 보증 가입 안내 원문은 별개다. 추가 공개 API를 쓰게 되면 그 서비스의 공식 발급처를 확인하고 필요한 키만 준비한다.

## 발급 이후의 별도 작업

- 신청 상태·허용 서비스·출력 형식·이용조건·호출 제한을 확인하고 키 원문 없이 준비 상태를 기록한다. 이번 조사로 고정 호출 한도·비용·만료 조건을 확정하지 않았다.
- OC는 [CRED-001](specs/11_api_credential_vault_spec.md)의 암호화 보관 원칙으로 관리한다. 기존 보관함에 저장할 수 있다는 것과 법령 API 어댑터가 구현되었다는 것은 다르다. 실제 연결은 서비스 종류와 credential ID를 명시한다.
- 실제 호출 전에는 [수집 절차](../../../docs/data-collection.md)의 승인·중복 대조·범위 예약을 따른다. 인증값이 URL 파라미터인 API의 HTTPS/리다이렉트·요청 로그 마스킹은 연동 시 검증하고 기존 비밀 경계와의 계약도 확인한다.
- 원본 bytes·해시, 법령ID/MST·시행일·수집시각·조문 위치를 보존하고 검수한 뒤 별도 프로젝트에서 색인·평가한다. 기관 보증 안내는 기관/상품·문서 버전·효력·원문 위치를 별도 보존한다.

## 수집한 기준 스냅샷

2026-10-21 사용자의 RAG 사전 데이터 수집 요청에 따라 법제처 국가법령정보센터에서 다음 현행 시행본의 원문 응답을 로컬 보존했다. 인증 API 호출이 아니라 공식 본문 페이지의 공개 HTML/본문 응답을 수집했으며 OC는 사용하지 않았다.

| 문서 | 보존 버전 | 상태 |
| --- | --- | --- |
| 주택임대차보호법 | 법률 제21065호 · 공포 2025-10-01 · 시행 2026-01-02 | 원문·페이지 응답 보존, UTF-8/버전/제1조/부칙 표식 확인 |
| 주택임대차보호법 시행령 | 대통령령 제36423호 · 공포 2026-06-23 · 시행 2026-07-01 | 원문·페이지 응답 보존, UTF-8/버전/제1조/부칙 표식 확인 |

원본 4개 HTML, manifest, 검수 보고서를 담은 로컬 ZIP은 [법령 현행 스냅샷 패키지](../data/raw/legal_rag/legal_rag_law_current_20261021_v1.zip)다. 개별 원본·manifest와 ZIP 해시는 GitHub [수집 Issue #24](https://github.com/keulreobeu/jipdam/issues/24)에 기록한다. 공식 [이용안내](https://open.law.go.kr/LSO/information/guide.do)는 법령정보의 영리 목적 활용을 포함한 자유 이용을 안내하면서 출처 표시를 요구한다.

2026-10-21 최초 수집은 법제처 현행 법령 2건, 법무부 표준계약서, HUG 상품·절차·FAQ 및 2024-04-26 약관 HWP/PDF, HF 상품·약관·청구절차 자료, SGI 공식 안내 캡처를 포함했다. 이 초기 목록 이후 HUG/HF/SGI 약관 원문과 HUG 공식 2020 historical PDF가 추가됐고 페이지 검수/권리 기록도 보완됐다. 최초 v1 패키지 해시는 아래 각 시점의 기록으로 보존한다. 현재 패키지와 파일별 provenance는 위 2026-10-22 현재 수집 상태 및 Task를 기준으로 한다.

## 2026-10-22 법령정보 이용조건 재확인

법제처 [공식 이용안내](https://open.law.go.kr/LSO/information/guide.do)는 법령정보를 영리 목적을 포함해 자유롭게 활용할 수 있다고 명시하고, 출처 표시와 정확한 기관 귀속을 요구한다. 이용조건 위반, 제3자 권리 침해, 위조·변조 등에 대한 서비스 제한·주의사항도 함께 둔다. 이는 확보된 법령정보의 재사용 정책 안내이며 API 사용 승인과는 별개다.
