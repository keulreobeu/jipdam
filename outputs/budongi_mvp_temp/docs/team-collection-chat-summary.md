# 집담 데이터 수집 분담 — 채팅 공유용

각자 담당 데이터의 **원본 보존 → 정규화 → 건수·결측·오류 검증 → 제출**까지 맡습니다. 기존 거래·통계 자료는 재사용하고 중복 수집하지 않습니다. 아래 위치는 확보처이며, 유형에는 내용과 파일/서비스 형태를 함께 적었습니다.

| 담당 | 우선 준비할 데이터 | 확보 위치 | 유형·형태 |
|---|---|---|---|
| 1번 — 주거 안전·교육·의료 | 매매·전월세 실거래 / 기존 통계 | 프로젝트 공유 Drive·기존 DB | 거래 XML / 통계 XLSX·SQLite, **재사용** |
| 1번 | 전세보증 사고 / 공동주택 공시가격 | HUG / 국토교통부·공공데이터포털 | 지역 통계 XLSX / 평가액 CSV·API |
| 1번 | 어린이집·학교·병의원 | 어린이집 정보공개 / NEIS / 심평원 | 시설 위치·속성, API·파일 |
| 2번 — 재난·교통·생활 | 지하철역 / 버스 정류소·노선·도착 | 서울교통공사·서울 열린데이터 / TAGO·서울 교통데이터 | 좌표 CSV / 관계·실시간 API |
| 2번 | 마트·편의점·상가 | 소상공인시장진흥공단 | 시설 위치·업종, CSV·API |
| 2번 | 과거 침수 이력 | 생활안전지도 | 공간·지도 레이어, 분석 원본 제공 여부 확인 |
| 3번 — 건물·단지·보행 | 건축물대장 / 단지 기본·상세정보 | 건축HUB / K-apt | 건물 속성 API / 단지·주차·승강기 XLSX·API |
| 3번 | 보행 네트워크 | OpenStreetMap·Geofabrik | 공간 네트워크 PBF·GPKG |
| 3번 | 반려동물 허용·제한 | 관리규약·관리사무소 | 근거 문서·수작업 확인, 미확인은 unknown |

각 파트의 추가 데이터 후보:

- **1번:** 진료과·약국, 학교 교육환경, 학원·도서관·유치원, 어린이보호구역, 보육 평가, 연령별 인구·통학구역, 보증 연도별 통계.
- **2번:** 공원·운동시설, 홍수 위험, 교통사고, 대기질, 공영주차장, 첫차·막차·혼잡도, 역 출입구·엘리베이터, 대피시설, 소음·생활인구.
- **3번:** 동물병원·동반시설, 관리비·장기수선충당금, 에너지 사용·효율, 무장애 시설·경사·계단, 반려동물 놀이터, 전기차 충전, 유지보수 이력.

공통 규칙: **출처 ID·주소 원문·좌표 근거·기준일·원본 해시 보존**, 금액 원/면적 ㎡/거리 m, 결측 NULL. 내부 단지 ID는 통합 과정에서 발급·재사용하며 각자 임의 생성하지 않습니다. 실제 단지 매칭·좌표 검수·지표 계산식은 수집 후 결정합니다. 신규 수집 지역·기간은 기존 완료/예약 범위를 확인한 뒤 예약 시 확정합니다.

제출물: **원본 + 정규화 파일 + 스키마 + manifest + 검증 보고 + 재현 코드**. 제출 폴더는 `<source_id>/<batch_id>/` 구조를 사용합니다.

세부 확보처·전체 추가 목록·DB 연결·제출 절차: [상세 내역](team-collection-details.md). 공식 형식 확인 링크는 상세 파일의 각 데이터 행에 있습니다. 공통 스키마 원문은 [팀 데이터 계약](team-data-contract.md)을 따릅니다.
