## 범위

현 저장소의 보존·수집·통합·검수 기록을 바탕으로 실제 데이터군, 저장/검수 상태, 활용 예와 제한을 사람이 읽기 쉽게 정리한다. 기존 데이터·제품·평가 경계와 개별 원천의 승인 범위를 바꾸지 않는다. 실제 원본 세부는 연결된 manifest와 validation 문서가 정본이다.

## DATA-CATALOG-001-REQ-01 출처와 현황

가이드는 MOLIT 전월세/매매 원천과 canonical 통합, 사용자 제공 KB 통계, 임대차·보증 원문, 검수 serving snapshot을 각각 구분하고, 기간·수량·검수 상태를 근거 문서에 연결한다.

### DATA-CATALOG-001-AC-01

가이드의 데이터군·범위·현황이 현재 승인 Spec 및 validation 기록과 일치하고, 서로 다른 배치/산출물의 수치를 하나로 합치지 않는다.

## DATA-CATALOG-001-REQ-02 항목별 활용과 제한

각 데이터군마다 구체적인 활용 방법과 사용 전 제한을 함께 제공한다. 합성·미검수·미확정 데이터를 실제 수집·확정 추천 근거로 오인하지 않도록 상태를 표시한다.

### DATA-CATALOG-001-AC-02

표의 각 데이터 항목에 활용 예와 준비 상태에 맞는 제한이 있고, 거래 병합/단지 자동 확정/문서 권리 추정/수집 범위 확대를 승인된 사실처럼 제시하지 않는다.

## DATA-CATALOG-001-REQ-03 탐색과 검증 근거

가이드는 독자가 원본 근거와 현재 제품 준비 상태를 더 확인할 수 있도록 연결 문서와 기준일을 제공한다.

### DATA-CATALOG-001-AC-03

가이드에 기준일 및 관련 수집·canonical·통계·RAG·추천 serving 근거 링크가 포함되고 변경사항의 문서 검사가 기록된다.
