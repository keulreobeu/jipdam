# 개발 위키와 기록

실험, 시행착오, AI 활용, 문제 해결 기록은 이곳에 둔다. 각 기록은 날짜·입력/환경·실행 방법·관찰 결과·한계를 포함한다. 요구사항과 채택된 설계는 `docs/specs/`와 `docs/adr/`에 반영하며 Wiki를 공식 계약으로 사용하지 않는다.

[사용자 정책 v1.0](LIFECYCLE_POLICY.md)과 [자동 관리 운영](AUTOMATION.md)을 따른다.
기존 실험 기록을 자동으로 ACTIVE로 승격하지 않는다.
[Confluence 집담 개발 위키](https://kwulreobeu.atlassian.net/wiki/spaces/~7120201d82685826914674999dcbf004921921/pages/360449)를 사용한다.
관리 문서는 `pages/`, 상태·감사·복구 큐는 Git 제외 `.local_runtime/wiki-managed/`에 있다.

팀원도 같은 위키를 사용하며 권한이 없으면 [접근·편집 권한 요청 안내](TEAM_ACCESS.md)를 따른다.
