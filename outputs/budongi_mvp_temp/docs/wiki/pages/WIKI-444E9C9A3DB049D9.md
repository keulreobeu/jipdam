## 목적 및 적용 범위

Managed CLI의 공식 Usage·측정 완전성과 원본 benchmark item 품질을 확인한다. 현재 로컬 checkout 적용이며 실제 Baseline/절감률/Cloud/Claude 실측은 없다.

## 증상 또는 사용 상황

마지막 usage와 재시도 결과만 남으면 실패 비용과 턴별 사용량이 누락된다. 토큰 절감 주장은 완전성·독립 품질·승인 증거가 있어야 한다.

## 원인과 미확인 사항

기존 provider는 bounded stdout을 실행 종료 뒤 파싱했고 마지막 turn usage가 앞선 값을 덮었다. 새로운 observer는 별도 append-only metrics 원장에 수신 즉시 허용 필드만 기록한다.

## 실행 절차

저장소 루트에서 python -m harness report --task TASK-ID, python -m harness metrics runs --task TASK-ID, python -m harness metrics report --run RUN-ID를 실행한다. 실행 전에 metrics suite --request PATH로 원본 item/Task/AC·평가 hash를 고정하고 suite-report --suite ID를 확인한다. 독립 평가자는 controller의 .local_runtime/observability-evaluations/에 실제 JSON 근거를 저장하고 bytes hash·현재 run_revisions와 gates를 outcome --request PATH로 명시 기록한다. 자세한 요청 형식은 원본 운영 문서를 따른다.

## 주의사항 및 예외

이 outcome은 평가자의 수동 증명 기록이며 hidden test 실행기가 아니다. Usage 누락은0이 아니고 성공0 또는 partial이면 성공당 확정 토큰은 NULL이다. 프롬프트/응답/키/raw는 metrics에 저장하지 않는다. 외부 App/Cloud·Claude·GMS 실정산은 not_integrated이며 자동 귀속·추정 합산하지 않는다. objective 중복 등 최적화는 실제 Baseline 이후에 비교한다.

## 검증 방법 및 결과

비과금 관측성 fixture 29개, 기존 provider15개·managed13개 검사 통과. 스트리밍·재시도·중복 격리·누락·프로파일·승인·독립 평가 artifact를 확인했다. 실제 유료 모델·Cloud·토큰 절감률은 검증하지 않았다.
