# ADR-007 — 통계 관측은 거래 canonical과 분리한다

Status: Accepted. 2026-10-13 사용자의 통계 전용 공간·제공 파일 수입 요청. STATS-001/TASK-STATS-001.

선택: SQLite 전용 파일 `data/statistics/statistics.sqlite3`에 입력파일·시리즈·기간/차원별 통계셀과 배치 개정이력을 저장한다. 콘텐츠 원본은 별도 불변 아카이브다. 일반 통계표, 반올림 dashboard, 선도 비교 dashboard의 값은 source_view로 나눠 보존한다.

이유: 거래 DB는 계약별 원 정수/㎡/실제 출처 ID 계약이고, 통계는 집계 지수·가격평균·신고월 건수·설문 응답·PIR 분위 조합이다. 이를 거래행으로 변환하면 의미와 계보가 손실된다. 통계에 행정구역별 단지 연결을 자동 생성하지 않는다.

대안: 기존 canonical DB에 통계테이블 추가는 물리적 파일을 줄이지만 승인된 거래 스키마·불변 스냅샷의 마이그레이션이 필요하다. 사용자의 별도 공간 요구와 이후 메타데이터 보완을 전용 파일로 충족한다. 새 DB 서버/ORM은 불필요하다.

결과: 동일 통계가 서로 다른 표현으로 중복될 수 있으나 모든 원본을 보존하며 데이터셋·표현을 명시해 조회한다. 최신성은 수입배치 선택이며 원천 공표시각이나 수치 검수 완료를 추정하지 않는다.
