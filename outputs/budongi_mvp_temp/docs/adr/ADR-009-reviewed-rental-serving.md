# ADR-009 — 검수 관계 기반 serving과 공통 판정, 내장 지도

Status: Accepted. 날짜: 2026-10-14. 담당자: Codex.

근거: 사용자의 `PLEASE IMPLEMENT THIS PLAN`과 D1 내장 지도, D2 Leaflet+OSM, D3 공통 판정 선택. 관련: RENT-001, TASK-RENT-MVP-001.

## Decision

canonical은 읽기 전용으로 보존한다. serving v2는 별도 임시 파일에 재생성하고 무결성·계보·버전을 검사한 뒤 교체한다. 원본의 단지 ID는 추천 자격이 아니다. 오프라인 검수 패키지의 승인 근거·검수자·시각·원본 해시가 있는 확정 관계만 serving에 반영한다. 자료가 없으면 확정 연결 0건을 유지한다.

실제 canonical과 합성 rental_v1의 어댑터는 유지한다. 거리·커버리지·필수/선호·순위의 순수 판정 함수를 공유한다. latest-before-budget 규칙을 보존하고 최종 필수 판정 전에 후보를 제한하지 않는다. 시설은 RTree 후보 조회 후 실제 좌표로 계산한다.

Leaflet 1.9.4 자산과 라이선스를 로컬에 포함한다. 지도 보기 선택 때만 OSM 타일을 요청한다. 검수 좌표만 표시하고 타일 장애 때도 후보·좌표를 보존한다. 타일 외 지오코딩/시설 수집은 승인되지 않았다.

## Consequences

importer는 검수 자료를 소비하며 매칭을 생성하지 않는다. 합성 자료는 명시적 허용과 표시가 필요하다. 버전 변경은 재생성으로 적용한다. 실제 확정 자료와 실모델이 없으면 기능 검증과 실데이터 준비 검증을 구분한다. 기존 역사 Tool·합성 CLI 계약은 유지한다.
