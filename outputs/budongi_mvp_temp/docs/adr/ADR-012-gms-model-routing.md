# ADR-012 — 난이도별 GMS 선택과 공통 예산 원장

Status: Accepted. 날짜: 2026-10-14. 사용자 난이도별 SOL/LUNA 사용 요청.

단순 작업은 gpt-6-luna, 복잡 작업은 gpt-6.1-sol로 선택한다. 모델을 바꿔도 동일 정책/원장/선택 credential ID를 사용한다. 모델별 공개 GMS 요율은 서버 허용 목록이며 사용자 입력 요율을 신뢰하지 않는다. 카운트와 생성은 같은 모델/입력을 동결한다. 단위 올림은 비용을 과소 예약하지 않도록 적용한다.

작업은 max_output_tokens를 정책 이내로 낮출 수 있다. 난이도와 명시 모델 충돌은 실패하며 원격 실패 때 다른 모델로 자동 재시도하지 않는다. 과거 원장 행을 보존한 채 모델/요율 메타데이터를 별도 테이블에 저장한다. 추천 채팅의 로컬 모델 계약과 개발 초안 GMS를 구분한다.

추가 결정: 사용자 최신 지시에 따라 현재 선택 정책은 reserve_only다. 5,000 보존과 진행 중 예약/최대 비용만 비용 게이트로 사용한다. 누적 비용/토큰은 기록하며 실행을 막지 않는다. 과거 cumulative 정책은 호환성용으로 유지한다.
