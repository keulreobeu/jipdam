# ADR-005 — 원시 MOLIT 응답과 파생 DB 분리

상태: Accepted. 2026-10-12 사용자 구현 계획 승인. 관련 MOLIT-001, RENT-001, CRED-001, COLLECT-001.

XML은 수집 시점의 불변 원본이다. 서비스×구×월별 페이지 응답과 해시/시각/상태를 남기고 DB는 언제든 네트워크 없이 재생성할 파생물로 둔다. API 재호출을 파서 수정의 선행 조건으로 삼지 않는다. 전체 배치와 query manifest로 중단·재개를 추적한다.

공통 수집기는 원본 저장·페이지 검사·재개를 공유하고 서비스별 정규화는 분리한다. 기존 역사 수집기를 전면 교체하면 환경변수/원본 경로 호환성을 깨므로 그대로 보존한다. 전월세는 rental_v1을 재사용한다. 매매 일반·상세는 최신 별도 관측 DB에서 출처를 구분한다. 두 API의 같은 값은 동일 실제 계약 증거가 아니므로 자동 병합하지 않는다.

배치 내 조회 시각이 달라질 수 있으며 원천의 당시 상태나 취소/정정 완전성을 보증하지 않는다. 실제 단지 매칭·추천·시설은 이 결정 범위 밖이다.
