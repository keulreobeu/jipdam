# ADR-010 — GMS의 제한된 연결 시험

Status: Accepted. 날짜: 2026-10-14. 근거: 사용자가 웹에서 변경 가능한 키로 GMS 사용 가능 여부를 확인하도록 요청했다. [GMS-001](../specs/17_gms_connection_spec.md), [Task](../tasks/gms-connection.md).

기존 AES-GCM/Windows Credential Manager 보관함과 loopback 설정 서버를 재사용한다. 범용 원격 LLM 프록시 대신 고정 Responses 요청을 한 번 보내는 adapter를 둔다. 키 ID는 사용자가 직접 선택하며 별칭/폴더로 GMS 키를 추측하지 않는다. 브라우저 직접 호출은 키 노출과 CORS 의존 때문에 채택하지 않는다. 키를 임시 환경변수로 옮기는 방식은 기존 보관함의 메모리 경계를 불필요하게 넓히므로 채택하지 않는다.

등록은 무통신이고 별도 연결 버튼만 비용을 사용한다. endpoint/model/input/출력 상한을 서버에서 고정하고 자동 재시도/리다이렉트/동시 호출을 막는다. 실제 usage가 있을 때만 비용을 계산하며 429는 쿼터 또는 속도 제한으로 표시한다. 사용시간은 토큰과 호출 빈도의 가정값이며 실잔액/실속도는 아니다.

현재 승인에 따른 GMS 연결 확인은 CRED-001의 사용자 승인 외부 호출 조건을 충족하는 한정 경로다. 이전 수집 보류나 추천의 로컬 LLM 경로를 변경하지 않는다. 실제 키/모델의 성공은 사용자 시험 전까지 미검증이다.
