## 공유 시 함께 전달할 해석

- 매매 일반과 매매 상세는 서로 다른 API에서 온 별도 관측이다. 두 행 수를 합친 값은 **중복 제거된 계약 건수**가 아니다.
- 기간 밖 9,319행도 원본 및 제외 사유와 함께 staging에 보존했다. 유효 행은 설정된 관측 기간에 해당하는 행이다.
- 자료는 API 조회 시점에 제공된 응답이다. 과거 시점의 동일한 원본 상태나 향후 정정·완전성을 보증하지 않는다.
- 데이터 출처 검수 및 단지·주소 매칭은 이 수집 단계의 완료 범위가 아니다. 이 단계는 원본 수집과 관측 DB 생성·검증 완료를 뜻하며, 추천용 통합 DB 전체의 완료를 뜻하지 않는다.

세부 실행 증거와 이전 상태의 구분은 위 검증 문서를 참고한다. 수집 Task는 [TASK-MOLIT-001](tasks/molit-collection.md)에서 추적한다.
