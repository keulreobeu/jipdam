    보존 크레딧과 사용 한도

    SOL 입력/출력 0.02/0.1 · LUNA 입력/출력 0.001/0.005크레딧/토큰

    선택한 키에 저장합니다. 비활성·만료·입력 카운트 실패·입출력 상한 초과는 실행하지 않습니다. 잔액 보존 모드는 보류·최대 예약 차감 후 설정한 최소 잔액(1,000크레딧 이상)을 유지하며, 이전 모드는 누적·호출 한도도 적용합니다.

    잔액은 팀의 다른 사용에도 변합니다. 이 앱은 자체 호출만 제한하며 매 실행 전 실제 잔액을 다시 조회합니다. 사용량 없는 실패는 최대 비용·토큰을 보류합니다.

    명확한 코드 작업 · 사전 견적

    
      
    GMS 입력 카운트 조회도 크레딧을 사용할 수 있습니다. 조회 비용을 먼저 예약하고 계정 사용량 차이로 대사합니다. 출력 예상량은 보장이 아니므로 최대 출력 비용을 예약해 usage로 정산합니다. 팀의 다른 차감이 섞이면 보수적으로 계산합니다. 코드 초안은 자동 적용하지 않습니다.
